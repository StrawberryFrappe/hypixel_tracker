# ADR 0006: Hypixel Compliance and Product Boundary

- Status: Proposed until user acceptance and policy review
- Date: 2026-07-13

## Context

The product uses the Hypixel Public API and ranks market opportunities. Official
policy requires respectful use, caching, no third-party API proxy, clear
unofficial branding, and protection of game integrity.

## Decision

Keep the product advisory-only and LAN-private. Do not automate game actions,
promise profit, imitate official branding, or expose a general public proxy.
Cache metadata, deduplicate Bazaar updates, record policy review dates, and show
freshness, fees, liquidity, and uncertainty with recommendations.

## Consequences

Policy changes can block collection or release. Compliance is a release gate,
not a documentation footnote.
