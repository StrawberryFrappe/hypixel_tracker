# Bazaar Guru

Bazaar Guru is a private, LAN-oriented market analysis project for the Hypixel
SkyBlock Bazaar. It is unofficial and advisory-only. It does not automate game
actions, proxy Hypixel data to the public, or promise profitable trades.

## Foundation Status

Release 1 scaffold currently provides:

- Versioned FastAPI health contracts.
- Independent Raw and Application PostgreSQL migration tracks.
- A responsive Vue 3 terminal shell with honest unavailable states.
- Resource-bounded Compose topology and local HTTPS edge foundation.
- Reproducible Python and frontend dependency locks.
- Automated lint, test, build, documentation, Compose, and secret-scan gates.

Collection, curation, authentication, market APIs, scoring, exports, backups,
restore, and deployment remain planned. The interface intentionally shows no
fake market data while these capabilities are absent.

## Product Principles

1. Preserve source evidence before deriving advice.
2. Never present stale or missing observations as live.
3. Keep Raw and Application stores operationally separate.
4. Expose scoring assumptions rather than guaranteed-profit claims.
5. Keep all game actions under human control.

This documentation is sanitized for public publication. It contains no private
host details, credentials, payloads, or recovery artifacts.
